🔍 カード性能タブ

色んなカードを総合的、状況的(ACT1エリート等)、ざっくりどれぐらい活躍したか見れます。
ページの下の方に注目度ランキング、Act4 パフォーマンス Top 40、傾向値Top40もあります。
(注目度ランキングは削除する可能性があります)

❓ イベント分析タブの見方

各イベントの選択肢を時系列順に並べています。選択肢のラベルは 2026-10-27 からよりわかりやすくなりました。

🔍 ラン検索タブの使い方

様々な条件でランを検索できます。大まかな経路取りもわかります。
たとえば霊夢ルートのデッキを知りたい、ACT1でAOE攻撃をもってないランはどれぐらいあったんだろう？、マニアックなカードの使用者を知りたい等。

  • カードや展示品を指定して最終的なデッキを検索したい場合、ACT4 / Lv4(4以上でも可)を指定してください。
    ACT LVの指定がないと条件に一致したところが検索されます。
  • ACT,レベル,カード,展示品等の指定がある場合、プレイIDに表示されるrunIDのホバーに特定状態(例 状態 act1 Lv 7)なのか、最終デッキなのか、どの状況におけるものかの表示があります。

    • ※最終結果にはないが、道中採用していたものを検索することはできます。

  • 🔗共有リンクをコピーを押すことでその検索結果を共有できます。
  • デッキ枚数の隣の「プレイヤー名」に入れると、そのプレイヤー (部分一致・大小文字区別なし) のランだけに絞り込めます。空欄なら指定なし。入力中にログに存在するプレイヤー名が候補に出ます。共有リンクにも含まれます。

🕰️ 検索履歴の比較と IQR (Q1–Q3) 表示

検索後、画面下の「検索履歴の比較」に直近30件分の区間別 平均ライフ喪失/ターンが表と折れ線グラフで残ります。行やグラフの点をホバーすると、その検索条件の IQR (Q1–Q3) が表示されます。

  • ライフの符号: 区間ライフは回復込みの純損失 — 被弾が優位なら ‑、回復が被弾を上回るなら +。
  • IQR帯: グラフに Q1/Q3 の薄い破線と、その間を Q2 (中央値) が濃くなるグラデーション帯で表示。Q2 自体も短い破線で入っています。
  • ばらつきグラフ: 区間ごとの Q3−Q1 の幅 (ブレの大きさ) を折れ線で見られます。下に行くほど良い (ブレが小さい = 条件の成績が安定)。既定はオフ —「表示するグラフ」の「ばらつき・ライフ / ばらつき・ターン」をチェックすると出ます。
  • グラフの絞り込みと拡大: 比較グラフは 6枚 (区間別2 + ばらつき2 (既定オフ) + 累積2 (既定オフ)) を「表示するグラフ」チェックで選べます (チェックバーは常時表示・既定は 区間別ライフ / 区間別ターン のみ)。PC の横幅では表示が1〜2枚のときは縦を2倍にして大きく描画し、1枚だけのときは全幅。グラフをクリックすると全画面ポップアップで大きく表示されます (✕ / ESC / 背景クリックで閉じる。拡大表示でも行・凡例とのホバー連動や IQR 帯が有効)。モバイル (縦長/横長どちらでも) は縦横比が画面幅と連動するため高さは据え置きです。
  • サンプルが 2 ラン以上ある条件のみ計算。旧い履歴には帯が無いので、同じ条件で再検索すると付きます。

⚔️ 「遭遇した戦闘 (敵ごと)」グラフ

検索結果の下に表示される積み上げ棒グラフです。検索したラン集団の中で、各敵にどれだけ遭遇したか、そしてそのうちどれぐらいが苦戦した戦闘だったかを見られます。

  • ラベル: 👹=エリート、✨=特殊イベント、ボス=キャラ絵 (通常敵は接頭辞なし)。
    並び順は時系列 (Act → 種別 → Lv) で、ゲームを進める順に並びます。
  • 区間の背景色: 行の背景にうっすら色を敷いて区間を区切ります — 青 = 序盤 (lv0〜5) / 緑 = 中盤 (lv5〜10) / オレンジ = 終盤 (lv10〜15) / 紫 = エリート / ピンク = ボス / 黄 = 特殊イベント (通常敵の区切りはルート選択タブと同じ lv 帯、Act1〜3)。
  • ホバーの詳細: 棒 (または敵名) にホバーすると 遭遇数・苦戦率・苦戦内訳 (ライフ / スペル / 両方) と、HP変化 (被弾 = − / 回復 = ＋) とターン数の箱ひげ (Q0〜Q4 = min/Q1/中央値/Q3/max の数値をグラフ内に描画) を表示します。軸は同じ ACT・敵種別の行で共通 (そのグループの min〜max を動的に決定) — 通常敵はさらに Act 内の出現区間 (ルート選択と同じ lv0〜5=序盤 / lv5〜10=中盤 / lv10〜15=終盤) ごとに軸を揃えます。キャラクターを指定して検索したときは、さらに (参考) そのキャラの全ランの苦戦率・苦戦内訳と同じ箱ひげを同じ軸に薄め表示し、この検索に合致した自分のランとの比較になります。
  • スマホでの表示: 画面の狭い幅では長い敵名を自動的に折り返して小さめに表示し、棒グラフの領域を確保します (行間も広めに取ります)。
  • 棒の長さ: 既定は遭遇回数。グラフ上部のボタンで「割合ベース (全員の棒の長さをそろえて 100% 積み上げ)」に切り替えられます。
  • 濃色の部分 = 苦戦した戦闘: 🩸苦戦 (ライフ) / ⚡️苦戦 (スペルカード) / 🩸⚡️両方。軸側から苦戦した分だけ伸びます。
  • 棒の右端の数字 = 苦戦率 (苦戦した遭遇回数 / 遭遇回数)。
    棒にホバーすると、遭遇数・苦戦数などの内訳が表示されます。

※ ボスのスペルカードに関する値は推定値です。ログには「スペルカードを使われた」という事実が直接記録されないため、戦闘中のパワーの減少量から推定しています。
ボス戦では通常戦闘よりしきい値を緩めて判定しているため、実際の使用とは多少前後することがあります。

  • 表示が古い/変なときは Ctrl+F5 (強制リロード) を試してください

🧮 集計方法のまとめ

1. ログの収集とフィルタリング

公開されているログリポジトリ (lbol logs) から最新のログデータを自動で収集します。その際、以下の条件で分析に適したログだけを厳選しています。

  • Lunatic7 真エンドクリアのログのみを使用
  • 一部 MOD を除外 (ゲームバランスに影響を与える MOD が使用されたログは除外)
  • サンプルを増やすため、バニラのカードと展示品のみのログを抽出 (提示に MOD 品があってもピックされなければ反映される)
  • 不正が疑われるログの除外 (異常なステータス変動・不連続なデータなど)

2. プレイヤーごとのログ抽出 (サンプリング)

特定のプレイヤーのログが多すぎると、その人のプレイスタイルが全体に大きく影響してしまいます。これを防ぐため、各プレイヤーから抽出するログ数に上限を設けています。

ログ数が上限に満たないプレイヤーについては制限を適用せず、すべての有効ログを使用します。 上限を超えるプレイヤーに対しては、分位加重サンプリングによってログを選び出します。

  1. ログを新旧 4 グループに分割 (最古・やや古い・やや新しい・最新の 25% ずつ)
  2. 新しいグループから多めに、古いグループから少なめにランダム抽出

3. 読むときの注意

  • 実戦回数の少ないカードは要注意: 使用回数が少ないカードは数字の振れが大きくなります (少数サンプルは状況平均に寄せて補正していますが、目安として)。高い数字が出ても実績の少なさを考慮して読んでください。
  • 表示対象にならないカードがあります: 採用率・戦闘回数などの基準を満たさないカードは表示対象外です。初期カードの採用ギャップも表示されません。
  • 母集団の偏り: 集計は投稿されたログの集まりであり、無作為サンプルではありません。全体の傾向を掴むための参考値としてご覧ください。

※一次フィルタは、L7クリアではないラン、MODのあるラン、整合性のとれないラン等です。
最終チェックのNGは異常な数値変動のあるラン、MODはバニラに存在しないカード展示品のあるランです。
MODが導入されていてもバニラとほぼ同じ挙動をしているランは採用されます。
