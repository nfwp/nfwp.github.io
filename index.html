📖 概要 / Overview

📘 日本語

本グラフは、ローグライクカードゲーム 『東方光耀夜 (LBoL)』 における 各カードのパフォーマンスや共起関係を可視化したものです。 使用率・同時採用傾向・ルート選択など分析しています。 詳しい使い方等はゲーム内の使い方 を参照ください。

📗 English

This graph visualizes the performance and co-occurrence relationships of each card in the roguelike deck-building game “Touhou Lost Branch of Legend (LBoL)”. It analyzes factors such as usage rate, simultaneous adoption tendencies, route selection, and so on. For detailed instructions and other information, please refer to How to Use within the statistics section.
