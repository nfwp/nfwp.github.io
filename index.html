📘 日本語
  • 2026-11-21: 初期カードの採用ギャップを N/A 表示に変更 — 初期デッキに含まれるカード (例: 咲夜A の降雪決行) は「最終採用率 ÷ 初動期待値」が成立せず、実際とは異なる大きな値 (3〜60倍) が表示されていました。カード一覧の表・詳細・カード性能ホバーで N/A (初期カード) と表示し、採用ギャップの絞り込み対象からも除外します (初期デッキ情報を正として判定)。あわせて指標の計算方法ポップアップ (ⓘ) の採用ギャップの注意にも「初期カードは N/A」を追記しました。
  • 2026-11-20: 指標の計算方法ポップアップ (ⓘ) を追加 — カード総選挙・カード性能・カード一覧・類似ラン検索の指標名の横に ⓘ を置き、クリックすると「意味」「計算式 (いま見ているカードの実数値を代入)」「注意点」をその場で表示します。例: ドラフト勝率なら「勝ったペア 1163 ÷ 決定ペア 1375 = 84.6%」。ポップアップ下部の「使い方タブで詳しく →」から該当節へ移動できます。あわせてカード性能タブのホバー情報のタイプ行に「所有者」アイコンを表示 (キャラ所有 = アバター / 共通カード = 色マナ)。さらに類似ラン検索に「ログURLから入力」を追加 — 公開ログビューアの URL / プレイID を貼り付けると、そのランの最終デッキ+展示品を自動入力して診断します (統計登録ランのみ)。またURL を短縮 — 類似ラン検索はアドレスバーに条件を乗せない (条件はブラウザ内に保存・共有は 🔗 ボタンの短縮リンク)、ラン検索への 🔍 リンクも重い条件はブラウザ内受け渡しで短く。旧形式の共有リンクも引き続き開けます。類似ラン検索に🕘 診断履歴を追加 (最大 20 件・クリックで再診断・ホバー / ▾ でカード・展示品の内訳を表示)。共有リンクの短縮は is.gd に加えて v.gd / spoo.me への自動フォールバック + 結果キャッシュで安定化。
  • 2026-11-19: カード総選挙タブを改善 — 「最終採用率*」を「ドラフト採用率*」に改名し、カード一覧と同じ定義の「最終採用率*」を追加。詳細に Act別ピック率 (未保有時/保有時)・提示フロー (1回目/2回目以降のピック率)・ピック率 (見送りを含む選択割合) を追加。Pレート・合成Pスコアをカード一覧のフィルタ/詳細・カード性能タブ (Top40 ランキング・ホバー) にも展開 (実験的機能)。
  • 2026-11-19: 類似ラン検索のピン留めを強化 — ピンしたカードは「デッキと同じ枚数以上」所持のランのみを候補に (例: 昇天脚×2 をピン → 2 枚以上積んでいるランのみ)。
  • 2026-11-18: カード総選挙タブ (テスト機能 β) を追加 — カード一覧タブの次に入っています。A vs B で同時に提示されたカードの選択を「総選挙 (対戦)」とみなし、Pレート (Elo 方式のレート・平均 1000) と積み指標 (最終採用率*・平均枚数・2枚以上率) から合成Pスコアを算出。散布図・カード表・クリック詳細 (ドラフト勝率・よく負けた相手 Top5・カード性能の箱ひげ) 付き。*付きの数値は歴史喰いのような使用時消滅カードも含む実質値。キャラごとに独立推定のためキャラ間の数値は直接比較不可。詳しくは使い方タブへ。英語版 ( locales) も同時対応。
  • 2026-11-17: ラン検索を強化 — ①展示品タブの入手内訳をクリックで詳細表示 (分類ごとの %・件数・積み上げバー)。②敵グループフィルターの表示名解決を同名コードすべてに拡張し、「Act/Lv を指定した場合、その Act/Lv での遭遇のみに限定する」チェックボックスを追加 — 戦闘レコードにノード位置 (Act・Level) を記録するパイプライン拡張により、Act+Level+敵グループの厳密指定が可能になりました (ルート選択の敵 🔍 リンクは厳密モード)。③最終デッキ条件がマナ条件未指定時に効かない不具合を修正。いずれも検索履歴・共有リンク対応。

The Card Performance hover now also shows an Owner icon on the type line (character avatar / mana-color icon for Neutral cards). 📖 概要 / Overview

📘 日本語

本グラフは、ローグライクカードゲーム 『東方光耀夜 (LBoL)』 における 各カードのパフォーマンスや共起関係を可視化したものです。 使用率・同時採用傾向・ルート選択など分析しています。 詳しい使い方等はゲーム内の使い方 を参照ください。

📗 English

This graph visualizes the performance and co-occurrence relationships of each card in the roguelike deck-building game “Touhou Lost Branch of Legend (LBoL)”. It analyzes factors such as usage rate, simultaneous adoption tendencies, route selection, and so on. For detailed instructions and other information, please refer to How to Use within the statistics section.
